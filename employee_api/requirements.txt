# This file lists every third-party package this project needs.

#
# Package explanations
# ────────────────────
# fastapi            → The web framework. It lets you define URL
#                      routes (endpoints) using plain Python functions.
#
# uvicorn            → The server that actually RUNS the FastAPI app.
#                      Think of it like Apache/Nginx but for Python.
#
# mysql-connector-python
#                    → The official MySQL driver for Python.
#                      It lets Python talk to a MySQL database.
#
# python-dotenv      → Reads key=value pairs from a .env file and
#                      loads them into os.environ so secrets never
#                      live inside Python source code.
#
# python-multipart   → Required by FastAPI to accept file uploads
#                      (multipart/form-data HTTP requests).
#
# aiofiles           → Lets FastAPI read/write files without blocking
#                      the server while waiting for disk I/O.
# ─────────────────────────────────────────────────────────────
